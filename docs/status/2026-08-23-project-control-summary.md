# 项目总控总结（2026-08-23）

## 项目目标

构建 Amazon US → Ozon Russia 的内部商品卡生产工具：读取指定 Amazon 当前变体，生成受事实约束的俄语内容和图片方案，经人工审核后保存草稿，并可选择提交 Ozon。

## 已确认的产品边界

- 首批类目：收纳凳。
- 单次处理：10～30 个任务。
- 优先自动读取 Amazon；无法可靠获取时提示用户补充。
- 只处理链接对应的当前变体，不跨变体拼接。
- 图片只使用有权使用的商品图片。
- Ozon 默认只生成内部草稿；正式创建商品必须明确授权。
- 架构：模块化单体 + 后台任务。
